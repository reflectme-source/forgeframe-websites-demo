# Studio Luma — fictional website concept

Public, fictional **design demonstration** by ForgeFrame Labs. **Not a real client, salon or operational booking service.**

- Preview: https://reflectme-source.github.io/forgeframe-websites-demo/
- Pure static HTML/CSS/JS. No cookies, tracking, forms, real contact numbers or client data.
- Does **not** include a CMS: a real paid customer who needs self-service edits receives an agreed Webflow/Framer/WordPress editor setup.
- Images are loaded from Unsplash; verify the original license and subject releases before reusing them on a real client's paid website: https://unsplash.com/license
- The `noindex` robots directive is intentional for this fictional concept, not suitable for a real launched client site.
- Mobile menu works with keyboard and updates `aria-expanded`; content follows reduced-motion preferences.
- Must still pass visual QA and accessibility testing before using as a real client starter.

**All text, brand, services and studio identity are fictional.**
